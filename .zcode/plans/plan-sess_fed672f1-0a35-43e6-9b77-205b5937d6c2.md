## Library Organization — Year/Genre Metadata + Sort/Filter + Configurable Filing

### 1. Database: add Year + Subjects + Decade columns

**`internal/library/models.go`** — Add to Book struct:
```go
Year     int      `json:"year,omitempty"`
Subjects []string `json:"subjects,omitempty"`
Decade   string   `json:"decade,omitempty"` // "1810s", "1920s", or ""
```

**`internal/library/store.go`** — Schema migration (add columns, update FTS):
- `ALTER TABLE books ADD COLUMN year INTEGER DEFAULT 0`
- `ALTER TABLE books ADD COLUMN subjects TEXT DEFAULT '[]'` (JSON array)
- `ALTER TABLE books ADD COLUMN decade TEXT DEFAULT ''`
- Rebuild FTS5 to include subjects in the index
- New sort modes: `"year"`, `"decade"`, `"genre"`
- New query: `Genres()` returns distinct first-subject per book (for filter chips)
- New query: `ListByGenre(genre, sort, offset, limit)` filters by subject

### 2. Wire Year + Subjects from sources

**`internal/download/manager.go`** — When constructing `library.Book` from `sources.Result`, copy `Year` (parse int) and `Subjects` (from Result.Description split, or a new Subjects field on Result).

**`internal/sources/source.go`** — Add `Subjects []string` field to `Result` struct. Update adapters:
- OL: populate Subjects from `Subject[]` (currently crammed into Description)
- ZLib: no subjects in API, leave empty
- Gutendex: no subjects, leave empty

**`internal/library/cover.go`** — Extend `epubMeta()` to also extract `dc:date` → Year, `dc:subject` → Subjects from EPUB OPF.

**`internal/library/ingest.go`** — Compute Decade from Year during import: `(year / 10) * 10 + "s"`.

### 3. Configurable filing mode

**`internal/config/config.go`** — Add `FilingMode string` (default `"author-title"`). Options: `"author-title"`, `"genre-author-title"`, `"decade-author-title"`.

**`internal/library/ingest.go`** — When filing a book, compute the directory path based on the current filing mode:
- `author-title`: `Author/Title` (current default)
- `genre-author-title`: `Genre/Author/Title` (first subject, fallback "Uncategorized")
- `decade-author-title`: `Decade/Author/Title` (computed from year, fallback "Unknown")

Add `Relocate(mode string)` method to Store that moves existing files to the new layout.

### 4. Frontend: sort + filter + filing mode

**`frontend/src/pages/Library.tsx`** — Changes:
- Sort dropdown adds: Year, Decade, Genre
- Genre filter chips: horizontal scrollable row of pill buttons (one per distinct genre)
- Filing mode displayed as a small note under the Library heading
- `BookT` interface adds `year`, `subjects`, `decade` fields

**`frontend/src/lib/api.ts`** — Add `genres()` method to backend (returns string[]), update BookT.

### 5. Filing mode relocation

When the user changes filing mode in Settings, the app:
1. Updates Settings.FilingMode
2. Runs a background task that moves all library files to the new layout
3. Updates book_files paths in the database
4. Emits `library:changed` when done

This is a potentially long operation for large libraries — show a progress indicator.
